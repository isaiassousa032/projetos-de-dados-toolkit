# Recursos de apoio

Biblioteca complementar aos frameworks. Utilize recursos quando resolverem uma necessidade concreta do projeto.

- [DataOps](dataops/README.md): Git, CI/CD, testes, monitoramento e documentação.
- [Ferramentas](ferramentas/README.md): índice por finalidade e critérios de escolha.
- [Agentes de IA](prompts-ia/guia-agentes-ia.md): apoio opcional com revisão humana.
- [Prompts reutilizáveis](prompts-ia/prompts-reutilizaveis.md): planejamento, modelagem, revisão e documentação.
- [Referências](referencias/README.md): documentação oficial, bibliografia e materiais fornecidos.
- [Relatório de implementação](referencias/relatorio-migracao.md): inventário, adaptações, integridade e pendências.

Arquivos originais e PDFs são acervo de referência, não dependências para executar projetos. Os exemplos de comandos devem ser adaptados no repositório do projeto; esta biblioteca não instala ferramentas, configura serviços ou agenda pipelines.
