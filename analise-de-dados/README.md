# Análise de Dados

Escolha o processo pelo escopo da investigação. Os frameworks permanecem independentes e podem ser usados com SQL, Python, Power BI, Excel ou outras ferramentas.

| Framework | Quando usar | Como começar |
|---|---|---|
| [Lite](lite/README.md) | Exercícios, exploração e perguntas delimitadas | Consultar o guia, copiar o template e revisar o checklist |
| [Completo](completo/README.md) | Investigação com hipóteses priorizadas, múltiplos recortes e comunicação executiva | Diagnosticar a base, aplicar o método e preparar o resumo |

Uma análise pode começar pelo Lite e justificar maior profundidade depois. Amplie o processo quando novas fontes, risco ou necessidade de rastreabilidade exigirem; registre a mudança de escopo.

O [guia de primeiras perguntas](../compartilhado/guias/guia-primeiras-perguntas.md) ajuda a compreender novas bases. Para o Lite, consulte apenas as perguntas relevantes; ele não exige o diagnóstico completo. Os [materiais compartilhados](../compartilhado/README.md) aprofundam requisitos, qualidade e convenções.

Se a análise exigir modelos recorrentes, integração e histórico governado, consulte [Analytics Engineering](../analytics-engineering/README.md). Guarde código e dados no repositório do projeto, mantendo aqui apenas referências e exemplos reutilizáveis.
